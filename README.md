# apex-roofing
This template is built for Whop Websites and implements Payment Elements end-to-end (Checkout + CheckoutElement + ExpressCheckoutElement + the required BrandingElement) so Apple Pay / Google Pay and financing options (Klarna, Afterpay, Splitit, etc.) surface automatically; three one-time plans (inspection fee, project deposit, flat-rate service); a “Request an Estimate” form wired to the Whop Leads API; a deposit flow intended to save the payment method for later use; example server handlers for creating a final-balance invoice via the Whop Invoices API (auto-charge stored method or send for manual payment); and three custom whop.track events (estimate_requested, service_viewed, deposit_started) in addition to the automatic page-view and checkout events that fire on a hosted whop.site / whop.app domain. All client-specific content is centralized in a single config file so the template can be reused by swapping company name, services, and plan IDs.
